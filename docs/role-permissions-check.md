# 本地角色权限核查

2026-11-02 更新。账号和登录信息见项目根目录的 `AGENTS.md`。本轮核查覆盖角色规则、HTTP 闸门和真实 PostgreSQL 集成测试；未做逐角色浏览器操作或生产数据验收。

## 当前角色边界

| 作用域 | 角色或关系 | 边界 |
| --- | --- | --- |
| 平台 | `super_admin` / `admin` / `user` | 管理入口按超级管理员或平台管理员检查；平台用户管理仅超级管理员可用 |
| 工作空间 | `owner` / `manager` / `member` | 所有者维护资料、解散、调整他人角色；主管只能邀请或移除成员；成员按店铺指派工作 |
| 工厂工作空间 | 成员关系 | 成员行不设角色列；履约和商品维护分别检查来源授权 |

工作空间只接受三个角色值。旧 `admin` 别名、`operator`、`reviewer`、`viewer` 及未知值均被拒绝；不把未知角色视为只读用户。平台角色、工作空间角色和来源授权不相互替代。完整规则见 [账号与权限模型](architecture/account-permission-model.md)。
