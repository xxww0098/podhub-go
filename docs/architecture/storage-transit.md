# 中转桶（transit）

切片由工作空间所有者填写 Cloudflare R2 桶、公开地址和 API 令牌，一空间一桶，成员共享。保存前在真实对象上验证写入、公开/私有回读、列举和删除；填写后的真实外部链路仍待按实际桶验收。公共规则见 [存储设计](storage-common.md)。清理时间是回收策略，不是外部平台完成取图的保证。

中转桶是 **wasm 渲染产物的投递目标**：浏览器或渲染执行器把 PSD 切成图片后直接写入本桶，`upload` 任务提交后这些 URL 进入上架载荷。对象不在桶间复制，按工作空间的自动或手动策略回收；发送受理不证明外部平台已取图。

## 桶

| 项 | 值 |
| --- | --- |
| 物理桶 | 工作空间所有者提供的专用 Cloudflare R2 桶 |
| 公开域名 | 所有者填写的 HTTPS 公开地址（r2.dev 有开发限速） |
| 角色 | `transit` |
| 访问 | 公开 URL |
| 生命周期 | 所有者选择每天北京时间指定时间自动清理，或仅手动清理；默认 04:00 |
| 生产者 | 浏览器 wasm / 渲染执行器（`slice` 任务） |
| 投递 | 本桶即投递目标；`upload` 任务只登记，不复制对象 |
| 消费者 | 上架载荷中的公开 URL |

切片对象**不写** `storage_objects`，不参与引用表与回收器。

## 路径

```text
工作空间 R2 桶
└── podhub-slices/{配置 UUID}/uploads/
    └── {UTC-date}/
        └── {batch-ms}-{batch-uuid}/
            └── {sha256}.{jpg|png}
```

- 组合与解析规则固定：`ComposeBatchedKey` / `ParseUploadKey`。
- 日期由批次时间换算为 UTC；自动清理时间使用北京时间，两者独立，不随部署地区变化。
- 批次目录 `{batch-ms}-{batch-uuid}` 即代际标识。
- 服务端生成 key；浏览器、WASM 批次确认、SQL 媒体识别、发送与清理使用同一形状。工作空间归属由会话、存储配置和已验证租约确认，不从 key 推断。

## 写入与校验

1. 服务端生成批次与 key，签发短时 PUT。当前切片 PUT 接线不能证明分片上传也已可用。
2. wasm 渲染执行器直传切片：渲染完成即写，不等上架。
3. `slice` 任务提交渲染回执，服务端用 `KeyCurrent` 做代际判断：落在外代批次的切片按 `ErrStale` 拒绝。
4. `upload` 任务登记已提交的切片，其公开 URL 随后进入上架载荷；对象不移动、不复制。
5. 发送时重新解析 key：
   - key 不符合切片格式 → `media_foreign`
   - 批次超龄或工作空间中不存在匹配的已验证租约 → 拒绝发送
6. 对象按所选清理策略回收；桶间不发生复制。外部图片读取完成须独立核对。

- PUT 使用 `if-none-match: *` 拒绝覆盖；分片接入时也必须使用同一正式 key 与不可覆盖约束。
- 只接受批次形状的 key；非批次 key 一律 `media_foreign`。
- 健康检查图按 digest 识别，不计费、不作为媒体。

## 清桶

- 所有者可选择每天北京时间指定时间清理，或仅手动清理。新配置默认 04:00，策略变更从下一个设定时间开始。旧配置保留各自策略。清理仅处理对应 `podhub-slices/{配置 UUID}/uploads/` 下的规范切片 key，保留其他对象及新批次。
- 自动清理正在运行时不能更改策略；请求失败或仍在等待上传链接过期而释放租约后可以更改，切换手动会停止之后的自动重试，已删除对象不会恢复。
- 手动清理先记录请求，`worker-media-gc` 处理并回写状态；重复请求复用进行中的任务。旧批次的租约在删除前退休，后续准备和发送检查不再接受它们。
- 服务端用当前工作空间的加密桶级凭据执行列举及精确批量删除；`CLOUD_MEDIA_GC_DELETE` 关闭时不执行清理。
- 回执与预算存 `transit_clear_runs`，手动请求存 `workspace_slice_clear_requests`；多进程用租约认领，失败后重试。
- 部分删除失败或清桶未完成要告警，并在该轮设定时间之后继续补偿重试；没有只准固定瞬间运行的结束窗口。
- 已签发的 PUT 最长有效 15 分钟；清理至少等过该窗口再标记完成。已经开始但迟迟未完成的 PUT 仍可能在末次列举后落地，残留留待后续清理。
- 切换前的旧形状对象仍保留原公开 URL，但新解析器和自动清理不再识别它们。先核对在途上传及外部取图，再按对象清单单独清退，不能只等待批次到期。

## 发送窗口

| 项 | 值 |
| --- | --- |
| 批次有效期 | 4 小时 |
| 发送最大时效 | 当前有效租约内，且未被实际自动清理或手动清理请求退休 |
| 对象寿命目标 | 自动模式为下次设定的清理时间；手动模式保留到手动删除。删除失败或并发上传可能残留 |

批次有效期与发送时效限制服务端接受输入的范围，不构成最短可读期。例如清理前一分钟上传的对象仍可能在设定时间被删除。手动模式只关闭本应用的自动清理，Cloudflare 桶自身的生命周期规则仍须另行检查。

Ozon 的 import 受理、任务 imported 或本地队列完成，都不能证明图片已被平台转存。当前真实发布证据也没有证明转存完成，见 [技术验证清单](../precision-listing-verification.md)。清桶跨越外部取图的风险仍须验证并制定处理规则；本文不据此宣称链路具备稳定的图片保留保证。

## 管理界面

| 层级 | 内容 |
| --- | --- |
| 工作区 → 日期 → 批次 | 工作区名、上传时间 |
| 批次 → 图片 | 哈希、扩展名、大小 |

设置 → 工作空间 → 存储桶按实际前缀浏览，批次显示 UTC 时间和短标识，详情保留完整 key，并展示对象大小、修改时间、ETag、预览及下载。仅所有者可删除对象或提交全量切片清理。对象和文件夹删除需等待上传批次及最近一次上传授权或确认超过 16 分钟；目录内尚未上传但已有有效授权的对象也会阻止删除。容量最多扫描 100,000 个对象，未完成时显示“至少”，不把账户免费额度展示成桶容量上限。清理失败的跨日残留仍按实际列举展示。

## 验收

- 空白与非空 `keyPrefix` 下 key 输出一致，日期与批次时间一致。
- 超过 4 小时或早于实际清理栅栏的上传目录被拒绝；租约过期、退休、属于其他工作空间或公开地址不匹配时拒绝发送。
- 非批次 key 不被识别为可发送图片。
- 每日自动清理自工作空间设定的北京时间起认领并写回执，未完成可在之后重试；手动模式不认领自动清理。清理只删除截止时间之前的切片。
- 单次 PUT 目标已存在时拒绝覆盖；分片若接入，须另行验证同 key、完整证明、Complete 与 Abort 行为。
