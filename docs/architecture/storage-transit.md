# 中转桶（transit）

日期：2026-10-18。公共规则见 [存储设计](storage-common.md)。

中转桶是 **wasm 渲染产物的投递目标**：浏览器或渲染执行器把 PSD 切成图片后直接写入本桶，`upload` 任务提交后这些 URL 进入上架载荷。对象不在桶间复制，发送方取图后等待当日清桶。

## 桶

| 项 | 值 |
| --- | --- |
| 物理桶 | `podhub-transit` |
| 公开域名 | `https://transit.podhub.si` |
| 角色 | `transit` |
| 访问 | 公开 URL |
| 生命周期 | 固定上海时间每天 04:00 删除桶内全部对象 |
| 生产者 | 浏览器 wasm / 渲染执行器（`slice` 任务） |
| 投递 | 本桶即投递目标；`upload` 任务只登记，不复制对象 |
| 消费者 | 上架载荷中的公开 URL |

切片对象**不写** `storage_objects`，不参与引用表与回收器。

## 路径

```text
podhub-transit
└── {prefix}uploads/
    └── {UTC-date}/
        └── {batch-ms}-{batch-uuid}/
            └── images/teams/{workspace-uuid}/sha256/
                └── {sha256}.{jpg|png}
```

- 组合与解析规则固定：`ComposeBatchedKey` / `ParseUploadKey`。
- 日期由批次时间换算为 UTC；清桶时刻固定为上海时间 04:00，两者独立，不随部署地区或夏令时变化。
- 批次目录 `{batch-ms}-{batch-uuid}` 即代际标识。
- key 形状是三方共享协议（浏览器 wasm 组合、SQL 媒体识别、发送前校验），不修改。改它需要同时改三处，不是本设计的范围。

## 写入与校验

1. 服务端生成批次与 key，签发短时 PUT 或分片上传。
2. wasm 渲染执行器直传切片：渲染完成即写，不等上架。
3. `slice` 任务提交渲染回执，服务端用 `KeyCurrent` 做代际判断：落在外代批次的切片按 `ErrStale` 拒绝。
4. `upload` 任务登记已提交的切片，其公开 URL 随后进入上架载荷；对象不移动、不复制。
5. 发送时重新解析 key：
   - 工作区不符 → `media_foreign`
   - 批次超龄 → `media_expired`
6. 发送方取图后，本地对象等待当日清桶；桶间不发生任何复制。

- 单次 PUT 与分片上传目标一致；`if-none-match: *` 不可覆盖。
- 只接受批次形状的 key；非批次 key 一律 `media_foreign`。
- 健康检查图按 digest 识别，不计费、不作为媒体。

## 清桶

- 固定上海时间每天 04:00 触发，删除桶内全部对象，直到观测到空桶。
- 不设关闭窗口：04:00 之前发出的上传可能在清理时被删除，这是预期行为；发送窗口已保证在途草稿不超过 12 小时。
- 删除使用独立只删 token，bucket allowlist 只含 `podhub-transit`；生产环境必须显式开启，`CLOUD_MEDIA_GC_DELETE` 的「未设置=开启」只适用于假桶。
- 每个环境使用独立物理桶；不得靠 `keyPrefix` 在同一桶内区分环境，否则清桶会跨环境误删。
- 回执与预算存 `slice_r2_cleanup_runs`；指纹按角色计算，桶改名不会重置连续性。
- 窗口结束仍有对象、部分删除失败、清桶未完成都要告警，并留窗口外的补偿重试。
- 兜底生命周期：未完成分片 `AbortIncompleteMultipartUpload` 设为 1 天；对象保留期不配，清桶是唯一删除机制。
- 清桶与并发 PUT/Complete 存在竞态：最后一次列举之后落地的对象会留到次日，分片在窗口内 Complete 也能重新生成对象。清桶是卫生机制，不是一致性边界。

## 发送窗口

| 项 | 值 |
| --- | --- |
| 批次有效期 | 4 小时 |
| 发送最大时效 | 12 小时 |
| 对象实际寿命 | 至多 1 天 |

发送窗口必须小于对象寿命：超过一天未发送的草稿，图片必然已被清桶。12 小时与清桶窗口之间留出余量。

Ozon 取图是提交后立即发生的，不需要为异步审核预留长期可读窗口；发送成功即视为取图完成。若监控出现「清桶后仍在被请求」，按缺陷处理，而不是延长窗口。

## 管理界面

| 层级 | 内容 |
| --- | --- |
| 工作区 → 日期 → 批次 | 工作区名、上传时间 |
| 批次 → 图片 | 哈希、扩展名、大小 |

数据最多一天，界面文案应说明这是“当前在途批次”，不是归档。

## 验收

- 空白与非空 `keyPrefix` 下 key 输出一致，日期与批次时间一致。
- 超过 4 小时的上传目录被拒绝；超过 12 小时发送窗口得到 `media_expired`；工作区不符得到 `media_foreign`。
- 非批次 key 不被识别为可发送图片。
- 清桶在固定上海时间 04:00 执行并清空整桶、写回执；其他时刻不删除；到点即删，无宽限窗口。
- 单次 PUT 与分片上传得到同一 key；目标已存在时拒绝覆盖。
