# 工作空间切片 R2

切片存储归工作空间所有。只有工作空间所有者可填写、清理存储桶配置；配置、容量、对象浏览、预览、下载与删除也只对所有者显示和开放，其他成员在设置中看不到「存储桶」，直接调用相关接口返回 403。成员仍可通过工作台的上传流程使用空间共享桶写入切片。一个空间只保留一个有效配置，同一物理桶不能成为两个空间的有效配置。设置位于「工作空间 → 存储桶」，由所有者填写已有 Cloudflare R2 桶的端点、桶名、公开访问地址和 API 令牌，平台不代为建桶、不代为开通 R2。

## 首次使用

没有 Cloudflare 账号可[注册 Cloudflare](https://dash.cloudflare.com/sign-up)。在[进入 R2](https://dash.cloudflare.com/?to=/:account/r2/overview) 后完成官方订阅结账流程。需要有效付款方式，不限于信用卡；Cloudflare 的付款方式还包括 PayPal 等，实际选项以结账页为准。参阅 [R2 开通要求](https://developers.cloudflare.com/r2/get-started/)、[付款方式](https://developers.cloudflare.com/billing/understand/billing-policy/)。

所有者需先在 Cloudflare 控制台完成三项准备：

1. 创建存储桶。桶名须为 3–63 个小写字母、数字或连字符，首尾为字母或数字。
2. 开启公开访问，取得 `https://pub-<32 位小写十六进制>.r2.dev` 地址，或绑定自己的域名。r2.dev 是有限速的开发地址；[生产公开访问](https://developers.cloudflare.com/r2/buckets/public-buckets/)建议使用自有域名。
3. 创建 R2 API 令牌，权限至少包含对象读取、写入、列举和删除，并限制到该桶。参阅 [R2 凭据](https://developers.cloudflare.com/r2/api/tokens/)。浏览器直传还需为桶配置 CORS，允许本站来源的 GET、PUT 及 `Content-Type`、`If-None-Match`、`X-Amz-Checksum-Sha256` 请求头，参阅 [R2 CORS](https://developers.cloudflare.com/r2/buckets/cors/)。

填写四类字段：

| 字段 | 说明 |
| --- | --- |
| R2 端点 | `https://<32 位 Cloudflare 账户 ID>.r2.cloudflarestorage.com`，必须 HTTPS |
| 存储桶名称 | 上述 R2 桶名 |
| 公开访问地址 | 绑定到此桶的 HTTPS 域名，不含路径、端口、查询或用户信息 |
| Access Key ID / Secret Access Key | R2 API 令牌的 S3 凭据 |

[标准存储免费额度](https://developers.cloudflare.com/r2/pricing/)每月含 10 GB-month，属于整个 Cloudflare 账户共享额度，不是每个桶的容量上限。超出后按量计费。

保存前，服务端使用填写的凭据执行真实验证：条件 PUT 写入测试对象、浏览器来源 CORS 预检、私有签名读取、公开地址读取、列举，以及精确删除和删除后回读。只有全部通过才激活配置；任一步失败都不会保存为可用配置，界面显示对应失败代码。凭据使用 `CLOUD_INTEGRATION_CONFIG_KEY` 派生的密钥加密存储，响应和日志不返回 Access Key 或 Secret。

## API

所有接口使用本站会话，且仅工作空间所有者可用；其他成员返回 403。写接口沿用同源 CSRF 防护。完整 DTO 以 `api/openapi.yaml` 为准。

| 路径（前缀 `/api/workspace/slice-storage`） | 行为 |
| --- | --- |
| `GET` 前缀本身 | 所有者读取当前空间配置、删除能力与清理状态；不返回密钥，其他成员返回 403 |
| `POST` 前缀本身 | 所有者提交 `endpoint`、`bucket`、`public_base_url`、`access_key_id`、`secret_access_key`；验证通过后激活。已配置的空间返回现有状态，不重复写入 |
| `POST /clear` | 所有者请求清理切片，由 worker 处理 |
| `PATCH /cleanup` | 所有者选择每天北京时间清理或仅手动清理 |
| `GET /objects` | 所有者分页浏览当前配置的 uploads 前缀，支持路径前缀、目录与游标 |
| `GET /stats` | 所有者列举当前切片实际容量及数量；未扫完明确返回 `complete: false` |
| `GET /download` | 所有者下载：为合法的当前配置切片 key 签发 5 分钟下载 URL |
| `POST /objects/delete` | 所有者删除指定切片或递归删除文件夹，每批最多 100 项，先退休租约再精确删除 |

每次保存生成新的配置 UUID，对象键固定为 `podhub-slices/<配置 UUID>/uploads/`。创建过程用空间级 PostgreSQL 会话锁串行化，避免两个请求同时验证并激活；物理桶唯一约束在 PostgreSQL 中兜底，已属于其他空间的有效桶返回 409。验证失败保留加密候选记录供已有对象清理，但不会显示为可用配置。当前不提供在已配置空间更换桶或凭据的入口。

## 切片复用与自动清理

上传准备按工作空间、当前存储配置及修订、SHA-256、扩展名和字节数查找对象。已验证对象返回 `transport: ready`，沿用原物理目录，不再 PUT，也不重复扣本月上传额度；同时续期四小时使用租约。尚未完成的并发首传共享同一对象键和一次额度预占，仍返回直传授权；条件 PUT 防止覆盖，每个调用者用自己的签名回执确认，pending 不当作成功。不同空间不共享复用，退休、删除、清理中、手动清理之前及超过 28 天提交时限的对象不能命中。前端检查服务端选定的物理批次；混合批次确认分别由完整对象键和签名票据限定。

冻结提交时，将切片来源 URL 写入不可修改的 `submission_intents.slice_image_urls`。Ozon 导入受理、任务完成或商品 ID 都不单独证明抓图成功；必须回读 `/v2/product/pictures/info`，确认同一商品、无图片错误、回执覆盖本次全部切片来源 URL，才保存回执和数据库时间 `slice_images_fetched_at`。若只返回无法对应来源的 CDN 链接，保留未知状态和切片，不按数量推断成功。网络失败、限流或仍在处理时延后重读，不重复导入。

每日自动清理只处理所有引用均确认抓图超过 24 小时、使用租约已过期、最后一次上传或复用超过 16 分钟的对象。待提交商品、活动任务、商品源图、供应商素材和长期媒体引用均阻止回收。引用写入持有共享身份锁；清理取得排他锁后以新数据库快照重查，再不可逆退休；R2 请求不持有数据库锁。分页会跳过受保护对象，继续处理后续页面，删除失败或查询失败按原回执机制重试。运行完成表示本轮可安全删除的对象已清理，不表示桶已清空。

迁移 `00039_slice_reuse_cleanup.sql` 增加冻结引用、抓图证据与索引。仅在新上传租约中标记 `slice_gc_tracked`；旧对象可能缺少历史引用证据，仍可复用，但不纳入自动回收。未使用、抓图失败或未知的切片也保留，可由所有者核对后手动删除。

此流程需要完成数据库迁移，并运行 reconciler 和媒体清理 worker。仅手动清理模式不执行自动回收。Cloudflare 自身的生命周期规则不受应用引用保护约束，不能另配短期强制过期来替代上述判断。未引入多账号、跨账号额度池或桶轮换。

## 数据迁移与管理范围

迁移 `00031_workspace_slice_storage.sql` 将个人表改为工作空间表。旧配置只映射给创建者拥有的一个未解散空间，优先其当前空间，否则选择最早空间。无法确定归属的配置及重复物理桶配置退休，凭据保留供原前缀清理。原配置 UUID、加密上下文和对象 key 保留，不复制云端对象。该所有权迁移不能自动安全回滚。

迁移 `00042_drop_slice_provisions.sql` 删除自动建桶阶段表；工作空间配置改为所有者填写。已有 `workspace_slice_storage` 行、桶和对象不受影响。

RLS 允许同空间读取，写入还检查实际空间所有者。创建者仅作为不可变的加密上下文保留，后续共享读取不按创建者过滤。上传、发送前检查和清理都使用当前空间配置。

管理仅覆盖本配置 `podhub-slices/<配置 UUID>/uploads/`，不展示或删除桶中的其他用途对象。对象和文件夹删除要求批次及最后一次上传授权或确认均已超过 16 分钟，避免尚有效的 PUT 授权重新写回；目录中已授权但尚未上传的对象也会阻止删除。文件夹通过含配置 UUID 的完整前缀绑定空间，拒绝根目录、其他配置与非规范路径；每批从目录重新列举最多 100 项，删除后回读，客户端在 `has_more` 为 true 时继续。遇到失败或未过期上传即停止并刷新，已完成的批次不会回滚；重试保留原租约退休时间。并发的新上传仍可能在删除完成后出现。成员没有删除入口，服务器删除开关关闭时按钮禁用。所有者可选择每天指定时间自动清理或仅手动清理；自动和全量手动清理通过 worker 执行，清理回执未确认时如实显示未知状态。

容量统计一次最多扫描 100,000 个对象、30 秒。达到页数上限时界面显示“至少”；上游失败显示统计不可用，不显示账户额度百分比。该统计是列举过程中的观察值，不是账单快照。

交互参考 [localflare](https://github.com/rohanprasadofficial/localflare) 的 R2 浏览、对象详情及下载管理，以及 [Nextcloud](https://docs.nextcloud.com/server/stable/user_manual/en/files/access_webgui.html) 的目录导航与缩略图网格。管理页以文件夹图标和图片网格展示，按内容区宽度自动换列；保留前缀搜索、上一级与面包屑、选择、下载及递归删除，缩略图懒加载并提供失败回退。未引入参考项目的存储服务，也没有把本地模拟结果作为 Cloudflare 外部证据。

## 验证

本地 PostgreSQL 测试覆盖迁移、所有者写限制、空间共享与跨空间隔离、物理桶唯一性、候选加密落库、失败验证后恢复及 RLS。固定上游测试覆盖 CORS、公开/私有回读、列举、精确删除、浏览器来源校验和错误脱敏。

2026-11-04 起移除 Cloudflare OAuth 与自动建桶：删除 OAuth 客户端、授权回调、账户列表、桶级凭据签发和 `workspace_slice_provisions` 阶段表。改为所有者填写端点、桶名、公开地址和 API 令牌，并由服务端执行同一套真实验证。本地 Go/架构测试、前端类型检查与构建通过；真实 Cloudflare 桶仍按填写值验收，尚未在本轮使用生产凭据执行。
